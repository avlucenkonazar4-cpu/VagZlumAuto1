# VagZlumAuto — редагування в одному місці

## Де міняти сайт
Відкрий `config.py` у Thonny.

У цьому файлі зібрані налаштування сайту:
- назва, заголовки, місто, адреса та графік;
- телефони для всіх кнопок «Зателефонувати»;
- меню;
- марки та моделі;
- швидкий підбір Golf / Jetta / Passat / Touran та цілих марок Renault / Ford / Dacia;
- паливо, коробки, кузови та привід;
- усі поля «Додати авто»;
- усі детальні характеристики автомобіля;
- додаткові послуги та їх описи;
- ремонт та ціни;
- усі основні тексти, кнопки та повідомлення;
- ліміт фотографій;
- стандартні дані адміністратора.

## Важливо
Автомобілі, які вже додані на сайт, зберігаються у `vagzlumauto.db`. Їх можна змінювати через «Додати» → «Існуючі авто» → «Редагувати» або видаляти там же.

`config.py` керує налаштуваннями та довідниками, а база — реальними оголошеннями.

Після зміни `config.py` збережи файл і перезапусти `app.py`.
